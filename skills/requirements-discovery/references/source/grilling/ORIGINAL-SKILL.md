# Grilling

## Scope

Read `references/local-execution-contract.md` at task start. This skill is task-specific and local-only. Do not activate remote integrations, persistent modes, hooks or unrelated implementation.

## Workflow

1. Map the design tree and separate observable facts from user-owned decisions.
2. Investigate facts from local evidence. Ask all currently independent decision questions with recommendations.
3. Wait for actual answers, recompute the frontier and continue until the agreed scope is resolved.
4. Summarize shared understanding and request confirmation where still needed.

## Default output

Decision tree with confirmed answers and unresolved frontier.

## Failure boundary

Report the missing input or capability; do not fabricate evidence or broaden the task.
