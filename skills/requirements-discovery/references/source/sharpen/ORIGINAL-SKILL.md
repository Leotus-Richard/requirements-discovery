# Sharpen

## Scope

Read `references/local-execution-contract.md` at task start. This skill is task-specific and local-only. Do not activate remote integrations, persistent modes, hooks or unrelated implementation.

## Workflow

1. Identify the actual goal, expert method, evidence needed and specification gaps.
2. Remove constraints that do not serve the goal and retain user-owned decisions as open.
3. Choose one outside check against the result, then perform only the requested local task.

## Default output

The task result with a justified approach and observed outside check.
